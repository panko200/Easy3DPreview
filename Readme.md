Easy3DPreview  
製作者：panko200  
配布場所：https://github.com/panko200/Easy3DPreview

## 概要

YukkuriMovieMaker4 にて動作するプラグインです。  
ツールメニューに「簡単3Dプレビュー」ウィンドウを追加します。  
タイムライン上のアイテムを疑似的な3D空間上に配置してリアルタイムでプレビューできます。  
透視投影・平行投影の切り替え、マウスによるカメラ操作（オービット・パン・ズーム）に対応しています。

## 使用方法

1. プラグインをインストールして YMM4 を起動する。
2. ツールメニューから「簡単3Dプレビュー」を選択してウィンドウを開く。
3. タイムラインを再生・シークすると、現在フレームのアイテムが3D空間上に表示される。
4. マウス操作でカメラを操作できる。
   - **右クリック＋ドラッグ**：カメラのオービット（回転）
   - **中ボタン＋ドラッグ**：カメラのパン（平行移動）
   - **ホイール**：ズームイン／アウト
5. 「透視投影 / 平行投影」ボタンで投影モードを切り替えられる。
6. 「リセット」ボタンでカメラをデフォルト位置に戻す。

## アンインストール方法

1. YMM4 を起動して `ヘルプ(H)` > `その他` > `プラグインフォルダを開く` をクリックする。
2. YMM4 を終了する。
3. `Easy3DPreview` という名前のフォルダを削除する。

## 注意点

OS : Windows11 (64bit)  
ゆっくりMovieMaker4 : v4.51.0.3  
にて動作確認をしています。

本プラグインは YMM4 内部の描画パイプラインに Harmony ライブラリを用いてパッチを当てることで動作します。  
YMM4 のアップデートによって動作しなくなる場合があります。
